# ShopEase – E-Commerce Website

ShopEase is a modern e-commerce frontend project developed as part of **Week 5: Advanced Frontend Development** during my full-stack development internship. It focuses on building a clean, responsive shopping experience using React.

## 🚀 Features

- **Modern UI:** Clean white and light-grey design.
- **Product Browsing:** Explore products through an organized shopping interface.
- **Shopping Cart:** Add products to the cart and manage cart items.
- **User Authentication:** Frontend authentication and registration features (where implemented).
- **Responsive Design:** User-friendly layout for different screen sizes.
- **Interactive Components:** React state management and reusable UI components.
- **Checkout:** Planned next feature.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Language:** JavaScript (ES6+)
- **Styling:** CSS3
- **Build Tool:** Vite
- **Package Manager:** npm
- **Version Control:** Git and GitHub

## ⚙️ Installation and Setup

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/Anjali-Verma1301/Fullstack_internship.git
```

### 2. Navigate to the Week 5 folder

```bash
cd Fullstack_internship/week5
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Open the local URL displayed in your terminal, usually:

`http://localhost:5173`
